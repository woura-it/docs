L'équipe Woura vous aide pour tout ce que ce guide ne règle pas. Pour une réponse rapide, donnez-lui les bonnes informations dès le premier message.

## Par où nous joindre

<CardGroup cols={2}>
  <Card title="WhatsApp" icon="message-circle">
    Dans l'application, cliquez sur le bouton vert en bas à droite, « Contacter le support sur WhatsApp ».
  </Card>
  <Card title="Formulaire de contact" icon="mail" href="https://woura.africa/fr/contact">
    Page **Contactez-nous** du site Woura : prénom, nom, e-mail, sujet, message, puis **Envoyer le message**.
  </Card>
</CardGroup>

Vous pouvez aussi écrire à **contact@woura.africa**.

## Ce qu'il faut nous envoyer

- l'adresse e-mail de votre compte Woura ;
- le nom de la boutique concernée ;
- ce que vous vouliez faire, et ce qui s'est passé ;
- le message d'erreur exact, ou une capture d'écran ;
- s'il y en a un, le numéro de la commande (`#0007` ou `WS-…`).

<Tip>
  Si l'écran affiche une ligne **Détail pour le support**, copiez-la dans votre message : elle nous fait gagner beaucoup de temps.
</Tip>

<Warning>
  N'envoyez jamais votre mot de passe, vos clés WooCommerce ou un code reçu par SMS. L'équipe Woura ne vous les demandera jamais.
</Warning>

## Ce qui passe par le support

Certaines actions ne se font pas encore depuis l'application. Demandez-les au support :
- déconnecter ou supprimer une boutique Shopify, WooCommerce, YouCan ou WhatsApp ;
- déconnecter un numéro WhatsApp ;
- changer l'adresse e-mail de votre compte ;
- obtenir un nouveau modèle de message WhatsApp pour vos campagnes.
