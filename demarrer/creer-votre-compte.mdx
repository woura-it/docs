Votre compte Woura vous donne accès à l'application et à l'éditeur de boutique. L'inscription est gratuite, et vous commencez sur le plan **Gratuit**, sans carte bancaire.

## Avant de commencer

Préparez :
- une adresse e-mail que vous consultez : Woura y envoie un code de vérification ;
- votre numéro de téléphone, de préférence celui de votre WhatsApp professionnel.

<Tip>
  Vous avez un compte Google ou Facebook ? Vous pouvez vous inscrire en un clic avec **Continuer avec Google** ou **Continuer avec Facebook**. Vous n'aurez alors pas de mot de passe à retenir.
</Tip>

## Créer votre compte

<Steps>
  <Step title="Ouvrez la page d'inscription">
    Allez sur [woura.africa](https://woura.africa) et cliquez sur **Essai Gratuit**, en haut à droite. Sur la page de connexion, cliquez sur **S'inscrire**, en bas.

    <Frame caption="La page « Créez votre compte ».">
      <img src="/images/demarrer/creer-votre-compte/01-inscription.png" alt="Formulaire d'inscription Woura avec les boutons Continuer avec Google et Continuer avec Facebook, puis les champs Prénom, Nom, Email, Téléphone et Mot de passe." />
    </Frame>
  </Step>
  <Step title="Remplissez le formulaire">
    Saisissez votre **Prénom**, votre **Nom**, votre **Email** et votre **Téléphone**. Choisissez d'abord l'indicatif de votre pays dans la liste, à gauche du numéro.

    Choisissez ensuite un **Mot de passe** et retapez-le dans **Confirmer le mot de passe**. Il doit contenir au moins 8 caractères, avec :
    - une majuscule ;
    - une minuscule ;
    - un chiffre ;
    - un caractère spécial, par exemple `!` ou `@`.
  </Step>
  <Step title="Acceptez les conditions">
    Cochez **J'accepte les conditions d'utilisation et la politique de confidentialité**, puis cliquez sur **Créer mon compte**.
  </Step>
  <Step title="Saisissez le code reçu par e-mail">
    Woura vous envoie un code à 4 chiffres. Tapez-le sur la page **Vérification du compte** : la vérification se lance dès le quatrième chiffre.

    <Frame caption="La page « Vérification du compte » attend le code à 4 chiffres.">
      <img src="/images/demarrer/creer-votre-compte/02-verification.png" alt="Page Vérification du compte avec quatre cases pour le code, le bouton Vérifier et le lien de renvoi du code." />
    </Frame>

    Pas de code au bout d'une minute ? Regardez dans vos courriers indésirables, puis cliquez sur **Renvoyer le code**.
  </Step>
</Steps>

<Frame caption="Sur téléphone, le formulaire tient sur une seule colonne.">
  <img src="/images/demarrer/creer-votre-compte/01-inscription-mobile.png" alt="Formulaire d'inscription Woura affiché sur un téléphone." style={{ maxWidth: "320px", margin: "0 auto" }} />
</Frame>

## Compléter votre profil et ajouter votre boutique

À votre première connexion, Woura vous guide en deux étapes. Le menu de l'application apparaît une fois votre première boutique ajoutée.

<Steps>
  <Step title="Profil">
    Vérifiez votre **Prénom**, votre **Nom** et votre **Numéro principal**, puis indiquez votre **Pays** et votre **Ville**. Cliquez sur **Accéder à mon espace**.

    Ce numéro sert à recevoir les alertes de votre boutique sur WhatsApp. Mettez celui que vous consultez vraiment.

    <Frame caption="Première étape : « Complète ton profil ».">
      <img src="/images/demarrer/creer-votre-compte/05-profil.png" alt="Étape Profil de l'accueil Woura avec les champs Prénom, Nom, Numéro principal, Pays et Ville, et le bouton Accéder à mon espace." />
    </Frame>
  </Step>
  <Step title="Boutique">
    Woura vous demande **As-tu déjà une boutique en ligne ?**
    - **Oui, j'ai déjà une boutique** : vous la reliez à Woura (Shopify, WooCommerce, YouCan ou WhatsApp). Voir [Choisir votre situation](/connecter/choisir-sa-situation).
    - **Non, pas encore** : vous créez votre boutique en ligne Woura en quelques minutes. Voir [Créer une boutique avec l'assistant](/boutique/creer-avec-assistant).

    <Frame caption="Deuxième étape : « Associe ta première boutique ».">
      <img src="/images/demarrer/creer-votre-compte/06-premiere-boutique.png" alt="Étape Boutique de l'accueil Woura avec les choix Oui, j'ai déjà une boutique et Non, pas encore." />
    </Frame>
  </Step>
</Steps>

## Vous connecter

Sur [woura.africa](https://woura.africa), cliquez sur **Essai Gratuit**. Vous arrivez sur la page de connexion :
- avec un e-mail : saisissez votre e-mail et votre mot de passe, puis cliquez sur **Se connecter** ;
- avec Google ou Facebook : cliquez sur le bouton correspondant.

Cochez **Se souvenir de moi** sur votre téléphone personnel : vous resterez connecté.

<Frame caption="La page de connexion.">
  <img src="/images/demarrer/creer-votre-compte/03-connexion.png" alt="Page de connexion Woura avec Continuer avec Google, Continuer avec Facebook, les champs Email et Mot de passe, et le bouton Se connecter." />
</Frame>

<Warning>
  Ne cochez pas **Se souvenir de moi** sur un ordinateur partagé, par exemple dans un cybercafé.
</Warning>

## Mot de passe oublié

<Steps>
  <Step title="Demandez un code">
    Sur la page de connexion, cliquez sur **Mot de passe oublié ?**. Saisissez votre e-mail, puis cliquez sur **Envoyer le code de réinitialisation**.
  </Step>
  <Step title="Saisissez le code et le nouveau mot de passe">
    Tapez le code à 4 chiffres reçu par e-mail. Choisissez ensuite votre **Nouveau mot de passe**, puis cliquez sur **Réinitialiser le mot de passe**.
  </Step>
</Steps>

## Questions fréquentes

<AccordionGroup>
  <Accordion title="L'inscription est-elle vraiment gratuite ?">
    Oui. Le plan **Gratuit** n'a pas de date de fin et donne 50 crédits chaque mois. Vous passez à un plan payant seulement si vous le décidez. Voir [Crédits et abonnement](/demarrer/credits-et-abonnement).
  </Accordion>
  <Accordion title="Je ne reçois pas le code de vérification.">
    Attendez une minute, puis regardez dans les courriers indésirables. Vérifiez aussi l'orthographe de l'e-mail affiché sur la page. Ensuite, cliquez sur **Renvoyer le code**. Si rien n'arrive, [contactez le support](/aide/contacter-le-support).
  </Accordion>
  <Accordion title="Mon mot de passe est refusé à l'inscription.">
    Il lui manque sans doute un des éléments demandés. Il faut au moins 8 caractères, avec une majuscule, une minuscule, un chiffre et un caractère spécial. Exemple de forme valable : `Karite2026!`.
  </Accordion>
  <Accordion title="Puis-je changer mon e-mail ou mon numéro plus tard ?">
    Votre numéro se modifie dans **Mon compte**, onglet **Profil**. Pour changer l'e-mail de connexion, [contactez le support](/aide/contacter-le-support).
  </Accordion>
</AccordionGroup>
