Un code promo, par exemple `BIENVENUE10` ou `TABASKI`, donne une réduction au client qui le saisit à la commande. Idéal pour une opération spéciale, un live ou vos premiers clients.

## Avant de commencer

- **La remise porte sur les articles, jamais sur la livraison.** Les frais de livraison restent dus en entier.
- Un code peut avoir un **achat minimum**, un **nombre maximal d'utilisations** et une **date de fin**. Les trois sont facultatifs.
- Un code ne se modifie pas après sa création : vous pouvez seulement l'activer, le désactiver ou le supprimer.

## Étapes

<Steps>
  <Step title="Ouvrez Codes promo">
    Dans l'éditeur, cliquez sur **Codes promo**, puis sur **Nouveau code**.

    <Frame caption="La liste de vos codes promo.">
      <img src="/images/boutique/codes-promo/01-codes.png" alt="Page Codes promo avec les codes TABASKI et BIENVENUE10, leurs utilisations et leurs conditions." />
    </Frame>
  </Step>
  <Step title="Remplissez le code">
    - **Code** : le mot à saisir. Il est mis en majuscules (40 caractères au plus).
    - **Type** : **Pourcentage** (par exemple 10 %) ou **Montant fixe** (par exemple 1 000 F CFA).
    - **Réduction** : la valeur.
    - **Achat minimum** (facultatif) : le montant d'articles à atteindre.
    - **Utilisations max** (facultatif) : vide ou 0 = illimité.
    - **Fin de validité (facultatif)** : le code marche jusqu'à 23 h 59 ce jour-là.

    <Frame caption="La fenêtre « Nouveau code ».">
      <img src="/images/boutique/codes-promo/02-nouveau-code.png" alt="Fenêtre Nouveau code avec les champs Code, Type, Réduction, Achat minimum, Utilisations max et Fin de validité." />
    </Frame>
  </Step>
  <Step title="Créez">
    Cliquez sur **Nouveau code**, en bas de la fenêtre. Le code est actif tout de suite : partagez-le sur vos réseaux.
  </Step>
</Steps>

## Suivre un code

Chaque code affiche sa remise, son nombre d'utilisations (« Jamais utilisé », ou « 7 utilisations sur 100 max »), son minimum (« dès 5 000 ») et sa date de fin. Un code périmé porte le badge **Expiré**. L'interrupteur l'active ou le désactive, la corbeille le supprime.

## Ce que voit votre client

Dans le formulaire, le client clique sur **Vous avez un code promo ?**, saisit le code et clique sur **Appliquer**. La ligne **Remise** apparaît dans le récapitulatif.

<Frame caption="Côté client : le code appliqué et la remise dans le récapitulatif.">
  <img src="/images/boutique/clients/panier-commande/03-code-promo.png" alt="Formulaire de commande avec le code BIENVENUE10 appliqué et la remise dans le récapitulatif." />
</Frame>

Si le code ne marche pas, le client voit pourquoi : « Ce code a expiré. », « Ce code a atteint sa limite d'utilisation. », « Ce code s'applique dès … d'achat. », ou « Ce code n'existe pas. ».
