Woura vous prévient de ce qui compte : une nouvelle commande, une livraison, un stock bas, un abonnement qui expire. Ces alertes arrivent dans l'application, et aussi sur WhatsApp si vous l'avez activé.

## La cloche

La cloche, en haut à droite, affiche vos dernières notifications. **Tout marquer comme lu** les marque toutes lues, **Voir toutes les notifications** ouvre la page complète.

## La page Notifications

**Actualiser** recharge la liste, **Marquer cette page comme lue** marque les notifications affichées.

## Choisir ce que vous recevez

Dans **Paramètres**, onglet **Notifications** :
- **Préférences de notification** : les alertes dans l'application (nouvelle commande, commande livrée, alerte stock bas, abonnement, service client, agenda) ;
- **WhatsApp Business** : les alertes sur WhatsApp. Voir [Notifications WhatsApp](/connecter/notifications-whatsapp).

Sur téléphone, autorisez les notifications quand Woura vous le propose : vous serez prévenu même application fermée.
